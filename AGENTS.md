# Agent notes

## Commands

- `bun install`, `bun run typecheck`, `bun run lint` (zero warnings), `bun run test`, `bun run check:repository`
- Kotlin unit tests, from `android/` after `bunx expo prebuild --platform android --no-install`:
  `JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home ANDROID_HOME=$HOME/Library/Android/sdk ./gradlew :multicam-capture:testDebugUnitTest :tip-jar:testDebugUnitTest`
- Debug APK for one emulator ABI: `./gradlew app:assembleDebug -PreactNativeArchitectures=arm64-v8a`
- Sideload release APK: `./gradlew app:assembleRelease -PreactNativeArchitectures=arm64-v8a,armeabi-v7a` (signed with the debug keystore)
- `android/` and `ios/` are generated by prebuild and gitignored. After Expo patch bumps, a stale `ios/Podfile.lock` fails `pod install`; `cd ios && pod update --no-repo-update` fixes it.

## Shared contracts

- `tests/library/fixtures/android-recovery.json` is checked by both `RecoveryContractTest.kt` and `tests/library/recovery-contract.test.ts`. Change the Kotlin recovery rules and the fixture together.
- `Icon` only accepts names in `src/components/icon-sources.ts`, so a new SF Symbol needs an Android glyph there.

## Emulator e2e

- Use your own emulator port and Metro port, and `adb reverse tcp:<port> tcp:<port>`. Launch the dev client with
  `adb shell am start -a android.intent.action.VIEW -d "exp+open-multicam://expo-development-client/?url=http%3A%2F%2F127.0.0.1%3A<port>"`.
- Metro's file watcher can miss edits made after it started. If a JS change does not show up on the device, restart Metro with `--clear`.
- RN 0.86 does not forward `console.log` to Metro or logcat; surface debug values through UI text or accessibility labels instead.
- The emulator exposes one 1080p camera (front), no concurrent pairs, so two-camera modes cannot run there.
- `-gpu swiftshader_indirect` aborted the emulator under camera load; the default GPU works.
- Thermal states: `adb shell cmd thermalservice override-status 4` (critical), `0` to reset.
- uiautomator cannot dump while the recording timer or the video player animates; use screenshots then.
